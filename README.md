# Bookie · PE Reading Studio

一个以阅读为起点的私募股权学习工作台。它把 PDF 阅读、划线提问、学习计划、知识卡、面经训练和投资雷达组织在同一条长期学习路径中。

> 当前版本首先面向个人本地使用：书籍、OCR 文本、阅读记录和 API Key 都保存在使用者自己的浏览器与电脑中。

## 能做什么

- 上传书籍、研报或 PDF Presentation；系统按文件情况选择章节、页码或“一天读完”规划
- 上传可选中文字的 PDF，或对扫描版 PDF 进行浏览器本地整书 OCR
- 从真实阅读页码、阅读时长和提问记录生成简洁的中英双语回顾
- 使用官方最新 DeepSeek V4.1 Flash 进行陪读、翻译、解释、计划、技术模拟与知识整理
- 自动将阅读笔记、知识卡、面经资料和投资雷达资料按书籍、公司、行业与主题留档
- 生成按工作日 / 周末可用时长分配的逐日阅读计划；章节可靠时可跳到正文，目录无法确认时按页码阅读

## 本地启动

```bash
npm install
npm run dev
```

然后打开终端显示的本地地址。进入网站右上角的“AI 与数据设置”，粘贴你自己的 DeepSeek API Key 并保存。

## 成本与隐私

- OCR 在浏览器本地运行，不调用 AI API。
- 默认用官方最新 DeepSeek V4.1 Flash（`deepseek-flash`）。模型名称在 `lib/ai-models.ts` 统一配置；DeepSeek 更新稳定别名时只需修改这一处。
- API Key 不写入代码或 GitHub。当前个人版仅在浏览器会话中临时保存，并通过本站 API route 代理调用；关闭浏览器后需要重新粘贴。
- 网站会限制单次传给模型的上下文与最长输出，避免意外产生过多 token。
- API Key、PDF 与阅读数据不会被提交到本项目的代码仓库。
- 上传或使用任何 PDF 前，请确认你拥有相应的合法使用权。

## 技术栈

React · TypeScript · Vinext · PDF.js · Tesseract.js · IndexedDB · DeepSeek API

## 文件规划方式

- **章节**：仅在 PDF 目录连续、正文页可验证时自动启用；日任务可跳到对应正文。
- **页码**：用于长篇低清晰度 PDF 或 OCR 无法可靠确认目录的文件；系统按页码区间生成日任务。
- **一天读完**：适合篇幅较短、没有传统章节的研报、Presentation 或 Deck；可在书架选择。

长篇（超过 100 页）且 OCR 无法可靠识别目录的文件会自动按页码规划。短文件才提供“按页码 / 一天读完”选择，避免不必要的设置。
