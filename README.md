# Bookie · PE Reading Studio

一个以阅读为起点的私募股权学习工作台。它把 PDF 阅读、划线提问、学习计划、知识卡、面经训练和投资雷达组织在同一条长期学习路径中。

> 当前版本首先面向个人本地使用：书籍、OCR 文本、阅读记录和 API Key 都保存在使用者自己的浏览器与电脑中。

## 能做什么

- 上传可选中文字的 PDF，或对扫描版 PDF 进行浏览器本地整书 OCR
- 从真实阅读页码、阅读时长和提问记录生成简洁的中英双语回顾
- 使用 DeepSeek Flash 进行日常陪读、翻译、解释、计划与知识整理
- 使用 DeepSeek Pro 进行高难度 PE / 投行技术模拟
- 自动将阅读笔记、知识卡、面经资料和投资雷达资料按书籍、公司、行业与主题留档
- 生成可点击、按周管理的学习计划，并追踪章节完成情况

## 本地启动

```bash
npm install
npm run dev
```

然后打开终端显示的本地地址。进入网站右上角的“AI 与数据设置”，粘贴你自己的 DeepSeek API Key 并保存。

## 成本与隐私

- OCR 在浏览器本地运行，不调用 AI API。
- 默认用 DeepSeek Flash；仅技术模拟使用 DeepSeek Pro。
- 网站会限制单次传给模型的上下文与最长输出，避免意外产生过多 token。
- API Key、PDF 与阅读数据不会被提交到本项目的代码仓库。
- 上传或使用任何 PDF 前，请确认你拥有相应的合法使用权。

## 技术栈

React · TypeScript · Vinext · PDF.js · Tesseract.js · IndexedDB · DeepSeek API

## 项目状态

这是一个持续迭代中的个人学习产品原型。未来版本可加入用户登录、云端备份、个人域名和按用户隔离的存储。
